# ぴたトラック

動画ファイルと複数の音声ファイルを1つのMP4にまとめ、各音声トラックにトラック名を付けるためのWindows向けツールです。（旧名: ffmpegMp4Mix）

`ffmpeg` を使って、MPC-BEなどのメディアプレイヤーで音声トラック名が分かりやすく表示されるMP4を作成します。

## できること

- ZIPを展開して `setup` を開くだけでインストール（ffmpeg も自動で用意）
- 右クリックの **送る**、またはファイルのドラッグ＆ドロップで起動
- 動画ファイルが先頭でなくても、最初に見つかった `.mp4` を動画として使用
- トラック名の初期値設定
- 元動画の音声を1トラック目に使うか選択
- 音声トラックごとに開始タイミングを早める・遅らせる（ミリ秒単位）
- 出力ファイル名の接尾語を設定
- CLI版バッチでも実行可能

GUI版のみ:

- GUIで動画と音声トラックを選んで結合
- トラック名の一覧表示、編集、候補からの選択
- トラック順の変更、追加、削除
- 動画として使うファイルと、音声トラックにある `.mp4` の入れ替え
- 動画の音声と比べて、各トラックのオフセットを自動調整

`GUI版のみ` の機能はGUI版だけで使えます。CLI版では、ファイル指定順と実行中の対話入力で処理します。

## どれを使えばいい？

| したいこと | 送るメニューの名前 | ファイル |
|---|---|---|
| 画面で確認しながら操作したい（GUI版） | ぴたトラック | `mixtrack_ffmpeg_gui` |
| 少ない操作で早く済ませたい（CLI版） | ぴたトラック (CLI版) | `mixtrack_ffmpeg` |

インストールすると、右クリックの **送る** に「ぴたトラック」と「ぴたトラック (CLI版)」が追加されます。

インストールせずに使う場合や、ファイルを直接ドロップする場合は、ルートにある `mixtrack_ffmpeg_gui` または `mixtrack_ffmpeg` を使います。
拡張子を表示していない場合、エクスプローラー上では `.bat` が見えません。

## フォルダー構成

通常使うドロップ先はルートに置き、内部ファイルは `tools` フォルダーにまとめています。
インストールした場合、このフォルダーは `%LOCALAPPDATA%\Programs\PitaTrack` にあります。

```text
PitaTrack\
  setup.bat                  セットアップ（インストール・更新）
  PitaTrack.exe              起動用（インストール時や tools\makesendto の実行時に作成）
  mixtrack_ffmpeg.bat        CLI版のドロップ先
  mixtrack_ffmpeg_gui.bat    GUI版のドロップ先
  README_ja.md
  README.md
  tools\
    ffmpeg.exe               セットアップか初回起動時にダウンロード
    mixtrack_ffmpeg_gui.ps1
    mixtrack_ffmpeg_gui.settings.json
    pitatrack.ico            アイコン
    setup.ps1
    makesendto.bat
    removesendto.bat
```

`ffplay.exe` と `ffprobe.exe` は必須ではありませんが、ffmpeg配布物から一緒に置いておいても問題ありません。

`PitaTrack.exe` は、黒い画面（コンソール）を出さずにGUI版を開くための小さな起動用ファイルです。配布ZIPには入っておらず、インストール時（または `tools\makesendto` の実行時）に、WindowsにあるC#コンパイラーでそのPC上に作ります。ショートカット、送るメニュー、アンインストールはこれを使います。VBScriptは使っていません。

## 動作環境

- Windows 10 または Windows 11
- PowerShell 5.x
- `ffmpeg.exe`

## インストール

### かんたんインストール（おすすめ）

1. [GitHub Releases](https://github.com/bee7813993/ffmpegMp4Mix/releases) から `PitaTrack_vX.Y.Z.zip` をダウンロードします。
2. ダウンロードしたZIPを右クリックし、**すべて展開** を選びます。
3. 展開したフォルダーの `setup` をダブルクリックします。
4. **インストール** を押します。
5. 「インストールが完了しました。」と表示されたら、**閉じる** を押します。

これで使えるようになります。

- ffmpeg（MP4を作るのに必要なソフト）は自動でダウンロードされます（約110MB）。自分で用意する必要はありません。
- 管理者権限は不要です。インストール先は `%LOCALAPPDATA%\Programs\PitaTrack` です。
- 右クリックの **送る**、デスクトップ、スタートメニューに「ぴたトラック」が追加されます。追加するものはインストール画面で選べます。
- インストールが終わったら、展開したフォルダーとZIPファイルは削除してかまいません。
- 以前 ffmpegMp4Mix を **送る** に登録して使っていた場合は、そのフォルダーの設定と `ffmpeg.exe` を引き継ぎます。以前の送るメニュー（mixtrack_ffmpeg）を削除するかどうかも、インストール画面で選べます。

`setup` を開いたときに「発行元を確認できませんでした。このソフトウェアを実行しますか？」と表示された場合は **実行** を、「WindowsによってPCが保護されました」と表示された場合は **詳細情報** → **実行** を押してください。インターネットから入手したファイルを開くときの確認です。

`setup` を開くと黒い画面が一瞬表示され、すぐにセットアップの画面に切り替わります。

#### 更新する

新しいバージョンのZIPで、同じ手順を行います。画面は「更新します」になり、設定と `ffmpeg.exe` はそのまま引き継がれます。

`mixtrack_ffmpeg.bat` は新しいものに置き換わります。CLI版の設定（`USE_VIDEO_AUDIO` など）を書き換えていた場合は、もう一度設定してください。

#### アンインストールする

Windowsの **設定 → アプリ → インストールされているアプリ**（Windows 10は **設定 → アプリ → アプリと機能**）で「ぴたトラック」を選び、**アンインストール** を押します。

ショートカット、送るメニュー、設定、`ffmpeg.exe` も削除されます。

### インストールせずに使う

ZIPを展開したフォルダーのまま使うこともできます。

1. ZIPを任意のフォルダーに展開します。
2. 右クリックの **送る** から使いたい場合は、`tools\makesendto` を実行します。
3. 初めて起動したときに `ffmpeg.exe` が見つからない場合は、ダウンロード画面が表示されます。**ダウンロード** を押すと `tools` フォルダーに置かれます。

`ffmpeg.exe` を自分で用意する場合は、[ffmpeg.org](https://ffmpeg.org/download.html) から入手したものを `tools` フォルダーにコピーします。

`tools\makesendto` を実行すると、エクスプローラーでファイルを選択して **右クリック → 送る → ぴたトラック** または **ぴたトラック (CLI版)** を選べるようになります。このとき、起動用の `PitaTrack.exe` をこのフォルダーに作ります。

`mixtrack_ffmpeg_gui` をダブルクリックしたり、ファイルをドロップしたりして開いた場合は、黒い画面が一瞬表示されてからGUI版が開きます。ファイル名に `&` などの記号が入っていてうまく渡せない場合は、`tools\makesendto` で登録した **送る** から開いてください。

送るメニューから削除したい場合は、`tools\removesendto` を実行します。以前の送るメニュー（mixtrack_ffmpeg_gui、mixtrack_ffmpeg）も削除します。

## 使い方: GUI版

GUI版では、画面上でトラック名や順番を確認しながら実行できます。

### ファイルを準備する

結合したい動画ファイルと音声ファイルを同じフォルダーに置きます。

ファイルの順番は重要です。ファイル名の先頭に番号を付けると、エクスプローラーで並べ替えやすくなり、意図した順番で渡しやすくなります。

例:

```text
01_video.mp4
02_audio1.m4a
03_audio2.m4a
```

### 送るから起動する

1. 動画ファイルと音声ファイルを選択します。
2. 右クリック → **送る → ぴたトラック** を選びます。Windows 11では、右クリック → **その他のオプションを確認** → **送る** の中にあります。
3. トラック一覧が表示されます。
4. 必要に応じてトラック名、順番、出力先を変更します。
5. **保存** を押すと `ffmpeg` が実行され、出力ファイルが作られます。
6. 終わったら **閉じる** を押します。

**保存** してもウインドウは閉じません。オフセットなどを直して、何度でも保存し直せます。

- 保存が終わると、画面下に「保存しました」と表示されます。
- 同じ画面で一度保存したファイルに保存し直すときは、上書きの確認を省略します。
- 出力ファイルをプレイヤーで開いたままだと、保存できないことがあります。その場合はプレイヤーで閉じてから保存し直してください。

送る起動時は、渡されたファイル順がトラックの初期順になります。GUI版では、実行前に並び替えできます。

デスクトップの「ぴたトラック」に、動画ファイルと音声ファイルをまとめてドラッグ＆ドロップしても起動できます。

### 単体起動する

デスクトップやスタートメニューの「ぴたトラック」を開くと、ファイル指定なしで起動できます。インストールせずに使う場合は、`mixtrack_ffmpeg_gui` をダブルクリックします。

- 動画欄の **参照...** から動画ファイルを選択
- トラック一覧の **+ 追加** から音声ファイルを追加
- トラック一覧へ音声ファイルや動画ファイルをドラッグ＆ドロップして追加
- 動画欄へ動画ファイルをドラッグ＆ドロップして差し替え

動画欄が空の状態で複数ファイルをトラック一覧へドロップした場合、最初に見つかった `.mp4` が動画欄に入り、残りが音声トラックとして追加されます。

### トラック名を編集する

- トラック名セルを直接入力できます。
- トラック名セルをクリックすると、登録済みのトラック名候補を選択できます。
- キーボード操作では、トラック名セルで `Alt + ↑`、`Alt + ↓`、または `F4` を押すと候補を開けます。
- 候補にない名前も直接入力できます。

### 音声の開始タイミングをずらす

- **オフセット(ms)** 列に、ずらす時間をミリ秒で入力します。
- `+500` で0.5秒遅らせ、`-500` で0.5秒早めます。`0` または空欄ならずらしません。
- トラック一覧の上にあるボタンやキーボードでも増減できます。

  | 操作 | ボタン | キーボード |
  |---|---|---|
  | 選択中のトラックを増減 | **選択トラック** の `-100ms` / `+100ms` | `Ctrl + ↓` / `Ctrl + ↑` |
  | すべてのトラックを増減 | **全トラック** の `-100ms` / `+100ms` | `Ctrl + Shift + ↓` / `Ctrl + Shift + ↑` |
  | すべてのトラックを指定した量だけずらす | **全トラック** の入力欄に値を入れて **ずらす**（入力欄で `Enter` でも可） | - |

  - 増減幅は設定の **オフセット増減幅(ms)** で変更できます（初期値: 100ms）。
  - キーボード操作は、画面のどこにフォーカスがあっても使えます。選択中のトラックは、トラック一覧で青く表示されている行です。
  - **ずらす** は、各トラックの今の値に入力した値を足します。トラック同士の差はそのまま残ります。
- 早める場合は、音声の先頭を切り取ります（再エンコードなし）。
- 遅らせる場合は、設定の **遅らせる方法** に従います。詳しくは [音声を遅らせる方法の違い](#音声を遅らせる方法の違い) を参照してください。
- 整数以外を入力した場合は、元の値に戻ります。

### オフセットを自動で合わせる

**自動調整** を押すと、動画の音声と各トラックを比べてずれを見つけ、オフセットに入れます。元動画の音声トラックは対象外です。

- 同じ曲のオンボーカル・オフボーカル、別の人の歌、キー違い、ライブ音源、アレンジ違いでも合わせられるようにしています。
- 伴奏が同じ音源どうしは 1ms 単位、アレンジ違いなどは 10ms 程度の精度です。
- 結果は信頼度で扱いを変えます。

  | 信頼度 | 扱い |
  |---|---|
  | 高 | オフセットに反映します。 |
  | 中 | オフセットに反映し、セルを黄色にします。念のため確認してください。 |
  | 低 | 変更せず、セルを赤くします。 |

- セルにマウスを乗せると、見つけたずれと信頼度が表示されます。
- 設定の **自動調整を常に行う** をオンにすると、ボタンを押さなくても次のときに自動で調整します。
  - 画面を開いたとき（全トラック）
  - トラックを追加したとき（追加したトラックだけ）
  - 動画を変えたとき（全トラック）
- 信頼度が低い（赤いセルの）トラックが残ったまま **保存** しようとすると、確認のダイアログを表示します。そのトラックのオフセットを手で直すか、**選択トラック** の±ボタン（`Ctrl + ↑` / `Ctrl + ↓`）で増減すると、確認の対象から外れます。全トラックをまとめてずらしても、対象のままです。
- 演奏の速さが違う音源（テンポの違うライブなど）は 1つのオフセットでは合わせきれないため、「テンポか長さが違う可能性があります」と表示します。
- 探せるずれは前後 180 秒まで、解析するのは各ファイルの最初の 15 分です。

### トラック順を変更する

- 行をドラッグ＆ドロップして並び替えできます。
- **↑ 上へ** / **↓ 下へ** でも移動できます。
- `.mp4` のトラック行を動画欄へドロップすると、上部の動画ファイルと入れ替えできます。
- `.mp4` のトラックを選んで **↔ 動画と交換** を押しても、同じように入れ替えできます。最初に見つかった `.mp4` 以外を動画にしたいときに使います。
- どのトラックが `.mp4` かは、トラック一覧の **種類** 列で確認できます（`MP4`、`M4A` など。元動画の音声は `元動画`）。
- **入力ファイル** 列にはファイル名だけを表示します。マウスを乗せるとフルパスが表示されます。

### キーボードだけで操作する

起動後、`Tab`、文字入力、`Enter` だけでも保存まで進められるようにしています。`Esc` でウインドウを閉じます。

## 使い方: CLI版

CLI版は、GUIを開かずに少ない操作で素早く結合したい場合に使います。

### ファイルを準備する

結合したい動画ファイルと音声ファイルを同じフォルダーに置きます。

ファイルの順番は特に重要です。CLI版では、実行前にトラック順を並び替える画面がありません。
ファイル名の先頭に番号を付けると、エクスプローラーで並べ替えやすくなり、意図した順番でCLI版に渡しやすくなります。

例:

```text
01_video.mp4
02_audio1.m4a
03_audio2.m4a
```

### 起動方法

- ファイルを選択して **送る → ぴたトラック (CLI版)**
- ファイルを `mixtrack_ffmpeg` にドラッグ＆ドロップ

最初に見つかった `.mp4` が動画ファイルとして扱われます。
それ以外のファイルは音声トラックとして追加されます。

ファイルの順番が重要です。音声トラックは、CLI版に渡された順に追加されます。

### 実行中の入力

1. 元動画の音声を1トラック目に使うか入力します。

   ```text
   0: 使用しない
   1: 使用する
   Enterのみ: 0
   ```

2. 各音声トラックのトラック名を入力します。

   何も入力せずに `Enter` を押すと、初期トラック名が使われます。GUI版で設定を保存している場合は、GUI版のトラック数ごとの初期トラック名が使われます。

3. 各音声トラックのオフセット(ms)を入力します。

   `+500` で0.5秒遅らせ、`-500` で0.5秒早めます。何も入力せずに `Enter` を押すと、表示されている初期値（ふつうは 0）が使われます。

   GUI版の設定で **自動調整を常に行う** がオンの場合は、トラック名の入力の前に自動調整を行い、その結果がオフセットの初期値になります。結果と信頼度は入力の前に表示されます。

   信頼度が低い（判定できなかった）トラックは、`Enter` だけでは進みません。`y` を入力すると 0 のまま進みます。数値を入力して指定することもできます。

4. 完了すると、動画と同じフォルダーに `元動画名_mixed.mp4` が作成されます。出力ファイル名の接尾語は、GUI版の設定（トラック数ごとの接尾語）に従います。

## 設定

### GUIで設定できるもの

GUIの **設定** ボタンから変更できます。

- トラック番号ごとの初期トラック名（トラック数ごとに変えられます）
- 出力ファイル名の接尾語（トラック数ごとに変えられます）
- トラック名候補
- 番号未設定トラックの初期名
- 音声を遅らせる方法と、再エンコード時のビットレート
- オフセットのボタンで増減する幅
- 自動調整を常に行うかどうか

GUIで保存した設定は `tools\mixtrack_ffmpeg_gui.settings.json` に保存されます（インストールした場合は `%LOCALAPPDATA%\Programs\PitaTrack\tools\mixtrack_ffmpeg_gui.settings.json`）。

初回起動時は、`mixtrack_ffmpeg.bat` の `TRACKNAME_1`、`TRACKNAME_2`、`TRACKNAME_3` ...、`TRACKNAME_LATER`、`OUTPUT_SUFFIX`、`DELAY_MODE`、`REENCODE_BITRATE` を初期値として読み込みます。

### トラック数ごとの初期トラック名と出力接尾語

設定画面の上にある **トラック数** で、編集する対象を切り替えます。

- **共通（下記以外のトラック数）**: 専用の設定がないトラック数で使う初期トラック名と出力接尾語です。
- **2トラックのとき** など: そのトラック数を選んで **このトラック数専用の設定にする** にチェックを入れると、共通の値を元にした専用の設定を作れます。専用の設定があるトラック数には「（専用）」と表示されます。
- チェックを外すと、専用の設定を削除して共通の値に戻します。チェックがないときは、そのトラック数で実際に使われる値を灰色で表示します。
- 専用の設定で番号を省いたトラックは共通の初期名を、出力接尾語を空にした場合は共通の接尾語を使います。

トラック数は、トラック一覧の行数（元動画の音声を使う場合はその行も含む）です。

- ファイルを渡して開いたときは、トラック数に合った初期トラック名と出力接尾語を使います。
- トラックを追加したときは、追加したトラックだけに、追加後のトラック数に合った初期名を付けます。すでにあるトラックの名前は変えません。
- トラック数が変わったとき、出力ファイル名を初期値のまま変えていなければ、新しいトラック数の出力接尾語に合わせて更新します。

### 音声を遅らせる方法の違い

オフセットをプラスにして音声を遅らせるときの方法を選べます。早める場合は、どちらを選んでも再エンコードしません。

| 方法 | GUIの表示 | CLIの値 | 特徴 |
|---|---|---|---|
| コピー（初期値） | コピー（再エンコードなし） | `copy` | 音質が劣化せず、処理も速いです。MP4のエディットリストで開始位置を記録するため、エディットリストに対応していないプレイヤーでは遅れずに再生されます。 |
| 再エンコード | 再エンコード（AAC） | `reencode` | 遅らせるトラックだけ、先頭に無音を足してAACで再エンコードします。どのプレイヤーでも遅れて再生されますが、わずかに音質が劣化します。 |

MPC-BE 1.9.1では、コピーで遅らせた音声が正しく再生されることを確認しています。

### CLI版で設定するもの

CLI版は、GUI版で保存した設定（`tools\mixtrack_ffmpeg_gui.settings.json`）で動作します。

- GUI版の設定が使われるもの: 初期トラック名（トラック数ごとの設定を含む）、出力ファイル名の接尾語、音声を遅らせる方法、再エンコード時のビットレート、自動調整を常に行うかどうか
- `mixtrack_ffmpeg.bat` の設定が使われるもの: 元動画の音声を使うか（`USE_VIDEO_AUDIO`）、MPC-BE 1.5互換モード（`MPCBE15_COMPAT_MODE`）

GUI版の設定をまだ保存していない場合は、以下の `mixtrack_ffmpeg.bat` の設定（トラック名・接尾語・遅らせる方法・ビットレート）が使われます。これらは、GUI版を初めて起動したときの初期値にもなります。

CLI版の設定は `mixtrack_ffmpeg.bat` を編集します。インストールした場合は `%LOCALAPPDATA%\Programs\PitaTrack\mixtrack_ffmpeg.bat` です。更新すると新しいものに置き換わるため、もう一度設定してください。

#### 元動画の音声を使うか

毎回問い合わせる代わりに固定したい場合は、`USE_VIDEO_AUDIO` を設定します。

```bat
set USE_VIDEO_AUDIO=1
```

値の意味:

- `0`: 元動画の音声を1トラック目にしない
- `1`: 元動画の音声を1トラック目にする
- 空欄: 実行時に問い合わせる

#### トラック名の初期値

```bat
set "TRACKNAME_1=オンボーカル"
set "TRACKNAME_2=オフボーカル"
set "TRACKNAME_3=歌手１ソロ"
set "TRACKNAME_4=歌手２ソロ"
set "TRACKNAME_LATER=トラック"
```

- `TRACKNAME_3`、`TRACKNAME_4` ... を追加すると、その番号の初期値になります。
- 設定されていない番号には `TRACKNAME_LATER` が使われます。

#### 出力ファイル名の接尾語

```bat
set "OUTPUT_SUFFIX=_mixed"
```

たとえば `_with_audio` にすると、出力ファイル名は `動画ファイル名_with_audio.mp4` になります。

環境変数 `OUTPUT_SUFFIX` が事前に設定されている場合は、その値が優先されます。

#### MPC-BE 1.5互換モード

MPC-BE 1.5でトラック名が重複表示される場合に使います。

```bat
set MPCBE15_COMPAT_MODE=1
```

- `0`: 通常モード
- `1`: MPC-BE 1.5向け互換モード

互換モードでは、MPC-BE 1.4や一部プレイヤーでトラック名が表示されなくなる場合があります。

#### 音声を遅らせる方法

```bat
set "DELAY_MODE=copy"
set "REENCODE_BITRATE=256k"
```

- `DELAY_MODE`: `copy` で再エンコードなし、`reencode` でAACに再エンコードして遅らせます。違いは [音声を遅らせる方法の違い](#音声を遅らせる方法の違い) を参照してください。
- `REENCODE_BITRATE`: `reencode` のときのビットレートです。

## 出力結果の確認

MPC-BEなどで以下を確認してください。

- 再生中のOSD表示
- 右クリックメニューの音声トラック選択
- コントロールバーの音声言語ボタン

## よくあるトラブル

### setup を開くと「セットアップに必要なファイルが見つかりません」と表示される

ZIPファイルの中から直接 `setup` を開いています。ZIPファイルを右クリックして **すべて展開** を選び、展開したフォルダーの `setup` を開いてください。

### ffmpeg.exe が見つからない

GUI版・CLI版とも、`ffmpeg.exe` が見つからないときはダウンロード画面を表示します。**ダウンロード** を押してください。

インターネットにつながらないなどでダウンロードできない場合は、[ffmpeg.org](https://ffmpeg.org/download.html) から入手した `ffmpeg.exe` を `tools` フォルダーにコピーしてください。
CLI版は `tools\ffmpeg.exe` を優先し、見つからない場合はルートの `ffmpeg.exe` も探します。

### 右クリックに「送る」が見当たらない

Windows 11では、右クリック → **その他のオプションを確認** を選ぶと **送る** が表示されます。

### .mp4 の動画ファイルが見つからない

選択したファイルの中に `.mp4` が含まれているか確認してください。
最初に見つかった `.mp4` が動画として扱われます。

### 送るメニューが古い場所を指している

インストールした場合は、新しいZIPの `setup` をもう一度実行してください。

インストールせずに使っていてフォルダーを移動した場合は、`tools\removesendto` で古いショートカットを削除してから、`tools\makesendto` をもう一度実行してください。

### CLI版の表示が文字化けする

`mixtrack_ffmpeg.bat` はWindowsのコマンドプロンプトで安定しやすいようにShift-JIS / `chcp 932` で動作します。
PowerShellや一部ターミナル上では表示が文字化けする場合がありますが、通常のコマンドプロンプトでは読める想定です。

### トラック名がプレイヤーに表示されない

プレイヤー側の表示仕様によって異なります。
MPC-BE 1.5で重複表示される場合は、`MPCBE15_COMPAT_MODE=1` を試してください。

### 遅らせたはずの音声が遅れずに再生される

再生しているプレイヤーが、MP4のエディットリストに対応していない可能性があります。
遅らせる方法を再エンコードに切り替えてください（GUIは **設定**、CLI版は `DELAY_MODE=reencode`）。

## 注意点

- 出力形式はMP4です。
- 映像と音声は再エンコードせず、基本的にコピーします。
- 遅らせる方法を再エンコードにした場合は、遅らせるトラックだけAACで再エンコードします。
- 入力ファイル名に `*`、`?`、`"`、`<`、`>` などWindowsで扱いにくい文字が含まれる場合、正常に動作しないことがあります。
- 括弧 `()` やスペースを含むファイル名には対応しています。

## 補足

これまで `L-SMASH Muxer` などで動画と音声を結合していた方向けに、より手軽にトラック名付きMP4を作れるようにしたツールです。

ぴたトラックは、以前は ffmpegMp4Mix という名前でした。

セットアップやダウンロード画面で取得する ffmpeg は、[gyan.dev](https://www.gyan.dev/ffmpeg/builds/) のWindows用ビルド（essentials、GPL）です。[GitHub上の配布ファイル](https://github.com/GyanD/codexffmpeg/releases)をダウンロードし、SHA256で内容を確認してから `ffmpeg.exe` を取り出します。

## 配布ZIPの作り方（開発者向け）

```bat
powershell -NoProfile -ExecutionPolicy Bypass -File dev\build_release.ps1
```

`dist\PitaTrack_vX.Y.Z.zip` が作られます。

- 版は `tools\setup.ps1` の `$Script:AppVersion` から読み取ります。リリース前にここを更新してください。
- gitで管理しているファイルだけを入れます（`dev` フォルダーと `ffmpeg.exe` は入りません）。新しく追加したファイルは、先に `git add` してください。
- ダウンロードする ffmpeg の版を変えるときは、`tools\setup.ps1` の `$Script:FfmpegUrl` と `$Script:FfmpegSha256` を一緒に変えます。
- アイコンは `tools\pitatrack.ico` です。差し替えると、次のインストール（または `tools\makesendto` の実行）から、`PitaTrack.exe`・ショートカット・画面のアイコンに反映されます。
